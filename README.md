# p-quizzz

App ôn luyện trắc nghiệm/tự luận chạy local trên máy mentor, member vào thi qua mạng LAN.
Business spec: [docs/PRODUCT.md](docs/PRODUCT.md).

## Chạy

```bash
npm install
npm start        # build UI + chạy server ở cổng 3000, in ra URL LAN cho member
npm run dev      # dev: Vite (5173) + Fastify (3000) với hot reload
npm test
```
