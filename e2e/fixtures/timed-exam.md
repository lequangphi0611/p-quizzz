## Lệnh nào tạo commit mới?
- [x] `git commit`
- [ ] `git push`
> `git commit` ghi lại thay đổi đã stage thành một commit.

## Lệnh nào tải thay đổi từ remote về và gộp vào nhánh hiện tại?
- [ ] `git fetch`
- [x] `git pull`
> `git pull` = `git fetch` + gộp.
